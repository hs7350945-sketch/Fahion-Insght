# 👗 ModaMetrics Dashboard

## Sobre o projeto

O ModaMetrics Dashboard é um projeto acadêmico voltado para o segmento de moda, desenvolvido para auxiliar na organização e visualização de informações relacionadas ao negócio.

## 🎯 Objetivo

O projeto tem como objetivo apresentar uma solução digital para facilitar o acompanhamento de informações do negócio, reunindo dados importantes em um dashboard organizado e de fácil visualização.

## 🚀 Principais funcionalidades

- Dashboard para visualização de informações
- Organização de dados do negócio
- Visualização de indicadores
- Acompanhamento de informações relevantes
- Interface organizada e intuitiva

## 🎨 Experiência do usuário

O projeto possui foco em UX/UI, buscando proporcionar uma experiência simples, organizada e adequada às necessidades do usuário.

## 🛠️ Projeto

Este projeto foi desenvolvido como parte da minha formação em Engenharia de Software, envolvendo planejamento, prototipação, organização de informações e experiência do usuário.
